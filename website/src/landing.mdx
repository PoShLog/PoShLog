:::note[PoShLog 3 is in preview]
It is a compiled module for PowerShell 7.4+ on Windows, Linux and macOS. Install it with `-AllowPrerelease`. On
Windows PowerShell 5.1, use the maintained [v2 line](v2-or-v3/).
:::

## Quick start

```powershell
Install-Module PoShLog -AllowPrerelease

Start-Logger -Console -FilePath './logs/app.log'

Write-InfoLog 'Copied {Count} files to {Target}' -PropertyValues 42, 'D:\Backup'

Close-Logger
```

## Why PoShLog

<CardGrid>
	<Card title="Structured, not just text" icon="document">
		Messages are templates: `{Count}` stays a number that Seq, Splunk or any log backend can filter and chart.
	</Card>
	<Card title="One logger, many destinations" icon="random">
		Send the same events to the console, a rolling file and a log server, each with its own minimum level and format.
	</Card>
	<Card title="Built on Serilog 4" icon="setting">
		Serilog's levels, enrichers and formatters, and Serilog 4 sink packages as an advanced route.
	</Card>
	<Card title="Fast and familiar" icon="rocket">
		A compiled binary module with the same cmdlet names and parameters as v2.
	</Card>
</CardGrid>

## Add a destination

PoShLog lists and installs its own extensions:

```powershell
Get-PoShLogExtension | Format-Table
Install-PoShLogExtension PoShLog.Sinks.Seq
```
